# OpenClaw Trace Analyzer

Metric-computation pipeline for OpenClaw + SWE-bench validation study.

## Purpose

Compute composition, resource, evaluation, and retry metrics from raw step traces,
telemetry time-series, and benchmark verdicts.

Addresses **RQ1 (composition)**, **RQ2 (resource bottlenecks)**, and **RQ3 (evaluation)**.
